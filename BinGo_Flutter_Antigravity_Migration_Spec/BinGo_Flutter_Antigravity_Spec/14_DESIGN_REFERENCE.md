# BinGo Design Reference — Supplied Screenshots

## Reference 1 — Schedule dashboard

The first screenshot shows a premium mobile schedule/dashboard concept.

Important visual observations:

- warm pale background
- centered phone-style composition
- top user identity chip
- circular notification button
- large white schedule card
- compact horizontal date pills
- selected date in bright lime/green
- white schedule/person cards
- rounded controls
- large data visualization
- floating bottom navigation
- selected Home item is a black/dark pill
- unselected navigation items are light circular controls

### BinGo interpretation

Replace:

- doctors → collection/schedule information
- appointments → waste collection events
- medical status → collection status
- health chart → useful BinGo collection metric only if current data supports it

Do not copy the medical content.

## Reference 2 — Data-rich home

Important visual observations:

- large greeting
- search-style control
- two-column metric cards
- one dark card beside a white card
- large weekly chart card
- schedule card below
- large whitespace
- restrained green accents
- black typography
- rounded corners

### BinGo interpretation

Possible BinGo equivalents:

- next collection
- waste type
- collection status
- weekly collection information
- schedule preview

Only use data that actually exists.

---

## Reference 3 — Onboarding

Important visual observations:

- full-height photography/illustration
- large image occupying upper/middle area
- subtle fade into background
- small category label
- very large title
- short supporting sentence
- large rounded bottom CTA
- simple success/check indicator
- minimal navigation chrome

### BinGo interpretation

Create onboarding around:

- smarter waste collection
- know your collection schedule
- segregate correctly
- participate in your local community

Use BinGo visuals/illustrations, not healthcare photography.

---

## Design principle

The desired result is:

> A premium native mobile BinGo application that feels modern, calm, spacious and polished, while retaining the complete existing BinGo functionality.
