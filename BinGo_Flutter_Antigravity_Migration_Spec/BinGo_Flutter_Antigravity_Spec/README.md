# BinGo Flutter + Antigravity Migration Pack

This pack contains the Markdown specifications and visual references for converting the existing BinGo web application to Flutter/Dart.

## Use

Give Antigravity:
1. The current BinGo household HTML.
2. The current BinGo admin HTML.
3. The current Firestore rules.
4. The current Google Apps Script verification file.
5. This entire Markdown pack.
6. The `design_references/` images.

Start with `00_MASTER_PROMPT.md`.

## Important

The existing source files are the functional source of truth.
The Markdown files define migration constraints, architecture, UI direction and acceptance tests.
The screenshots are visual references only.
